# Produktdateien (Infoprodukt)

Lege hier die ZIP-Dateien mit den Wallpapers ab. Nach bestätigter Stripe-Zahlung
kann der Kunde sie direkt auf der Bestätigungsseite herunterladen.

- `Atelier-Essential.zip` — Essenzielle Kollektion (100 Wallpapers)
- `Atelier-Premium.zip` — Premium-Kollektion (200+ Wallpapers)

Pfade können im Admin-Panel unter **Configurações → Produtos** geändert werden.
